# Triage labels

The engineering skills use these five canonical roles. The label names in GitHub match those roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill refers to a triage role, use the corresponding label. Reuse existing labels with these names and create only those that are missing.

Change the GitHub-label column if the repository adopts a different vocabulary.
